# 🚛 Sistema de Gestão de Frotas de Veículos

Este é um sistema backend para o gerenciamento de frotas de veículos e seus respectivos motoristas, com autenticação JWT e documentação via Swagger.

🛠 Tecnologias utilizadas
- Java 17+
- Spring Boot
- Spring Security
- PostgreSQL
- Swagger / OpenAPI
- Maven

⚡ Funcionalidades
- Cadastro e autenticação de usuários
- Gerenciamento de veículos e motoristas
- Gerenciamento de abastecimento e manutenção
- Endpoints protegidos por JWT
- Documentação interativa da API via Swagger
